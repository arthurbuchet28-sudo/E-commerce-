# Photos des voitures

Déposez ici 3 photos par voiture, au format JPG, nommées d'après le `slug` défini dans `js/cars.js` :

- `<slug>.jpg` : vue principale (trois quarts avant), utilisée sur les cartes
- `<slug>-2.jpg` : vue de profil
- `<slug>-3.jpg` : habitacle

Exemple pour la Ferrari Roma : `ferrari-roma.jpg`, `ferrari-roma-2.jpg`, `ferrari-roma-3.jpg`.

Format conseillé : 1600 × 1000 px (ratio 16:10), moins de 300 Ko.

Slugs : rolls-royce-cullinan, lamborghini-urus-s, ferrari-roma, mercedes-amg-g63, porsche-911-carrera-s,
mercedes-s500, range-rover-sport, audi-rs-q8, bmw-m4-cabriolet, nissan-patrol-nismo.

Tant qu'une photo manque, le site affiche automatiquement un bloc dégradé avec la marque et le modèle.
