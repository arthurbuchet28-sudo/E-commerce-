## Étape 1 : trouver vos concurrents (1 heure)

Cherchez comme le ferait votre client :

- dans un moteur de recherche, avec les mots qu’il utiliserait ;
- sur les <Terme id="marketplace">marketplaces</Terme> ;
- sur les réseaux sociaux, avec les mots-clés de votre thème ;
- dans les magasins physiques, qui sont aussi des concurrents.

Retenez cinq à dix concurrents qui visent **le même client** que vous, pas seulement le même produit.

## Étape 2 : les comparer dans un tableau (1 heure)

| Critère | Concurrent A | Concurrent B | Vous |
| --- | --- | --- | --- |
| Gamme et prix | | | |
| Frais et délais de livraison | | | |
| Politique de retour | | | |
| Qualité des photos et des fiches | | | |
| Ton et public visé | | | |
| Nombre et note des avis | | | |

Notez les faits, sans juger. Relevez aussi comment ils présentent leurs informations légales : une boutique sans mentions légales ni CGV n’est pas un modèle à suivre.

## Étape 3 : lire les avis négatifs (1 heure)

Les avis négatifs sont une mine : ils listent ce que les clients attendaient et n’ont pas eu. Délais trop longs, taille qui ne correspond pas, service client absent, emballage abîmé… Regroupez-les par thème : les thèmes qui reviennent sont vos opportunités.

<Exemple persona="karim">
  Karim vend des articles de cuisine. En lisant les avis de trois boutiques en ligne, il remarque
  que les clients se plaignent souvent de ne pas savoir quel ustensile choisir. Il décide d’ajouter
  des conseils simples sur ses fiches produits et le retrait en magasin.
</Exemple>

## Étape 4 : choisir votre angle (1 heure)

Votre différence doit être **précise** et **crédible** :

- un public plus ciblé (« pour les débutants », « pour les petits espaces ») ;
- un service meilleur (livraison plus rapide, conseils, retours simples) ;
- une fabrication ou une origine différente ;
- une expertise que vous pouvez démontrer.

Évitez de vous différencier uniquement par un prix plus bas : c’est la stratégie la plus facile à copier et la plus dangereuse pour votre marge. Vérifiez votre prix avec le [calculateur de prix et de marge](/outils/calculateur-prix-marge).

<Encadre type="legal" titre="Rester loyal">
  Comparer ses produits à ceux d’un concurrent nommé est encadré : la comparaison doit être
  objective et vérifiable. Et n’affichez jamais de faux avis ou de fausse urgence : ce sont des
  pratiques commerciales trompeuses.
</Encadre>
